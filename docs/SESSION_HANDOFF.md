## Learning style

The learner wants:
- very clear, simple explanations
- step-by-step learning
- practical implementation, not theory only
- official AWS references
- no invented AgentCore behavior
- code explained line by line when useful
- one component at a time
- explicit connection from current component to the next
- three perspectives:
  - beginner
  - intermediate technical
  - professional / production
