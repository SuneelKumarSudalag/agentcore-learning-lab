# AgentCore Learning Lab

A practical, step-by-step learning project for Amazon Bedrock AgentCore.

## Goal

Learn AgentCore by building one evolving application:

**Enterprise Multi-Agent RAG Research Assistant**

We will not learn AgentCore as isolated definitions. Each component will be introduced because the application needs it.

## Learning method

For each component:

1. Read the official AWS documentation
2. Explain the concept simply
3. Understand it from three levels:
   - Beginner
   - Intermediate technical
   - Professional / production
4. Build a small practical example
5. Explain important code line by line
6. Test it
7. Connect it to the application
8. Update the architecture
9. Record important decisions
10. Update progress before moving on

## Source of truth

Primary source: official AWS documentation.

https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/
